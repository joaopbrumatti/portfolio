Um relatório preso num tema de siteA report stuck inside a site theme

A versão antiga funcionava, mas morava dentro de um tema WordPress, com as chaves de acesso às contas de anúncio gravadas em arquivos do próprio tema. Mexer nela era arriscado, e cada relatório compartilhado dependia de alguém da equipe abrir e mandar print.The old version worked, but it lived inside a WordPress theme, with the ad account access keys stored in the theme's own files. Changing it was risky, and every shared report depended on someone on the team opening it and sending a screenshot.

A reescrita partiu de uma regra: nenhuma credencial do código antigo seria lida, copiada nem reaproveitada. O acesso novo nasce do zero, fica só no servidor e não aparece em log.The rewrite started from one rule: no credential from the old code would be read, copied or reused. The new access is created from scratch, stays on the server only and never appears in logs.

O que exigiu escolhaWhat required a decision

Link que não se adivinhaA link nobody can guess

O código do link é aleatório, com cerca de 49 bits, e não carrega informação: trocar uma letra não leva ao relatório de outro cliente. Os parâmetros são guardados no servidor e validados de novo ao abrir.The link code is random, about 49 bits, and carries no information: changing one letter does not lead to another client's report. The parameters are stored on the server and validated again on open.

Cache que nunca derrubaCache that never takes it down

As respostas da Meta e do GA4 ficam no KV. Um período já encerrado vale 24 horas; um período que inclui hoje, 10 minutos. Se o cache falhar, a consulta segue direto para a API, sem página de erro.Responses from Meta and GA4 are kept in KV. A period that has already ended is valid for 24 hours; a period that includes today, 10 minutes. If the cache fails, the query goes straight to the API, with no error page.

Sessão assinadaSigned session

O login antigo gravava a própria senha num cookie legível pelo navegador. Isso saiu. Agora o cookie carrega um token HMAC que expira em 12 horas, com HttpOnly e SameSite=Strict, e o login tem limite de tentativas.The old login stored the password itself in a cookie readable by the browser. That is gone. Now the cookie carries an HMAC token that expires in 12 hours, with HttpOnly and SameSite=Strict, and the login has an attempt limit.

Toda ação checa sessãoEvery action checks the session

Toda Server Action chama requireAuth() antes de tocar no banco. Ela é um POST endereçável e poderia ser chamada a partir de uma rota aberta, como o login.Every Server Action calls requireAuth() before touching the database. It is an addressable POST and could be invoked from an open route, such as the login.

Deploy que avisa antesDeploy that warns first

Um preflight de variáveis roda antes de cada build e trava se faltar segredo. Os erros que só apareceriam em produção, como a rota agendada devolvendo 503, viram falha de build.A variables preflight runs before every build and blocks it if a secret is missing. Errors that would only show up in production, like the scheduled route returning 503, become build failures.

Do localStorage para a produçãoFrom localStorage to production

A versão 2.0 do protótipo já tinha a ideia certa: lista de tarefas por frente de trabalho, funil de leads e exportação em CSV. Mas tudo morava no localStorage. Trocar de computador significava perder os dados, e o celular não via nada.Version 2.0 of the prototype already had the right idea: task lists per workstream, a lead funnel and CSV export. But everything lived in localStorage. Switching computers meant losing the data, and the phone saw nothing.

A reescrita manteve a lógica que já estava em uso e trocou a base: API num Worker, Postgres serverless e uma tela que funciona no toque. Depois disso o produto cresceu por pedidos dele e da equipe.The rewrite kept the logic already in use and swapped the foundation: an API on a Worker, serverless Postgres and a screen that works by touch. After that the product grew from requests by its user and the team.

O que exigiu escolhaWhat required a decision

Isolamento realReal isolation

Cada área tem senha e cookie próprios. Nenhuma página revela a existência das outras, e a API de uma não responde com a sessão de outra.Each area has its own password and cookie. No page reveals the existence of the others, and one area's API does not respond to another's session.

Nada derivado no bancoNothing derived in the database

"Atrasada", faixa de saldo e situação do cliente são calculados na leitura, a partir das datas. Um status gravado precisaria de alguém atualizando à meia-noite; um calculado nunca fica desencontrado."Overdue", balance band and client status are computed at read time, from the dates. A stored status would need someone updating it at midnight; a computed one never goes out of sync.

Saldo da Meta sem falso zeroMeta balance without a false zero

O saldo é o limite de gasto menos o valor já gasto. Conta sem limite definido não grava nada, porque um zero ali marcaria como esgotada justamente a conta que pode gastar à vontade. Cada sobrescrita guarda o valor anterior no histórico.The balance is the spend limit minus the amount already spent. An account with no limit set records nothing, because a zero there would mark as depleted exactly the account that can spend freely. Each overwrite keeps the previous value in the history.

Bloqueio de login no bancoLogin lockout in the database

Três erros em 30 minutos travam a origem, e um freio global fecha o login sob ataque distribuído. O IP entra só como HMAC truncado: o histórico conta tentativas sem registrar quem acessou de onde.Three failures in 30 minutes lock the source, and a global brake closes the login under a distributed attack. The IP is stored only as a truncated HMAC: the history counts attempts without recording who accessed from where.

CSP sem unsafe-inlineCSP without unsafe-inline

Nenhum script ou estilo inline. Os eventos entram por delegação, e a cor escolhida para cada tarefa é aplicada via CSSOM.No inline script or style. Events are attached by delegation, and the color chosen for each task is applied via CSSOM.

Migrações aditivasAdditive migrations

Cada mudança de schema é um script idempotente que só acrescenta. Uma tabela em produção nunca é recriada por engano.Every schema change is an idempotent script that only adds. A production table is never recreated by mistake.

O que mudou na rotinaWhat changed in the routine

As tarefas passaram a acompanhar o usuário do computador ao celular, e o funil de vendas ganhou um aviso de follow-up vencido. A operação de mídia da agência saiu de um PDF para um painel onde o saldo de cada conta se atualiza sozinho.Tasks now follow the user from the computer to the phone, and the sales funnel gained an overdue follow-up alert. The agency's media operation moved from a PDF to a panel where each account's balance updates itself.

Tudo roda num único Worker com banco serverless, sem servidor para manter.Everything runs on a single Worker with a serverless database, with no server to maintain.
